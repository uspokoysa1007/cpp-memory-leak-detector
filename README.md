# cpp-memory-leak-detector

Встраиваемый профилировщик и детектор утечек памяти на C++17.

## Возможности
- Перегрузка операторов `new`, `new[]`, `delete`, `delete[]` с макросом перехвата `__FILE__` и `__LINE__`.
- Потокобезопасный реестр активных аллокаций.
- Детальный отчет при завершении программы:
  - Точный адрес каждого неутеченного блока памяти.
  - Имя файла исходного кода и номер строки, где была выделена память.
  - Размер утечки в байтах.
  - Итоговая статистика: пиковое потребление, всего аллокаций, объем утекшей памяти.

## Сборка
```bash
g++ -O2 -std=c++17 src/main.cpp -o releases/cpp-memory-leak-detector.exe
```

## Использование
```bash
./releases/cpp-memory-leak-detector.exe
```
